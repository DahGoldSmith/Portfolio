# GitHub Pages Setup

1. Go to https://github.com/DahGoldSmith
2. Create a **Public** repository named `portfolio`.
3. Upload every file/folder in this portfolio package.
4. Commit them to `main`.
5. Open **Settings → Pages**.
6. Choose **Deploy from a branch**.
7. Choose `main` and `/(root)`.
8. Save.
9. Wait for deployment.
10. Open https://dahgoldsmith.github.io/portfolio/

Do not rename or remove the `assets` folder.
