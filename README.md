# Abdul Hashim Dusabe — Professional Portfolio

GitHub Pages portfolio.

## Publish
Create a **Public** repository named `portfolio` under `DahGoldSmith`, upload all files in this folder to the `main` branch, then go to:

**Settings → Pages → Deploy from a branch → main → /(root) → Save**

Expected URL:

`https://dahgoldsmith.github.io/portfolio/`

Keep the `assets` folder and its files together with `index.html`.
